# WeChat Clipper：URL 输入弹窗交互优化设计

## 背景

当前通过命令面板触发导入时，会打开一个自定义弹窗用于输入公众号文章 URL。现有输入框在布局与交互上与 Obsidian 的原生输入体验存在差异。

## 目标

- 输入框布局更贴近 Obsidian 原生输入体验：左对齐、可输入区域更长
- 支持在输入框内按回车直接触发 Import

## 非目标

- 不变更导入逻辑、解析逻辑、落盘规则与设置项
- 不引入全局样式文件或主题相关适配逻辑

## 设计方案

### 布局

- 保持现有弹窗结构：标题、URL 输入区、Import 按钮
- URL 输入框占满弹窗可用宽度并左对齐（随弹窗宽度自适应）

### 交互

- 弹窗打开时自动聚焦 URL 输入框
- Enter：触发 Import，与点击 Import 按钮一致
- Esc/关闭：保持现有行为，返回当前输入值或 null

## 验收标准

- URL 输入框在弹窗中表现为左对齐且可输入区域明显加长
- 在 URL 输入框内按 Enter 可直接开始导入
- 未输入或仅空白内容时触发 Import 会与现有逻辑一致（最终返回 null，不开始导入）
